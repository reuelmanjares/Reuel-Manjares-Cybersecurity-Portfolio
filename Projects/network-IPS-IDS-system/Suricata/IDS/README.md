## Overview

In this project I demonstrates the use of Suricata as an Intrusion Detection System (IDS) to monitor network traffic and detect reconnaissance activity in a controlled cybersecurity home lab.

The lab uses Kali Linux as the testing machine, Ubuntu running Suricata as the network monitoring system, and Windows Server 2022 as the target.

## Objectives

- Monitor TCP traffic generated during authorized Nmap scans.
- Create and test custom Suricata detection rules.
- Identify TCP SYN probes directed at the Windows Server.
- Analyze alerts recorded in Suricata's EVE JSON log.
- Compare packet captures with the alerts generated by the IDS.

## Lab Configuration

| Component | Role |
|---|---|
| Kali Linux | Generates controlled reconnaissance traffic |
| Ubuntu | Runs Suricata and monitors network traffic |
| Windows Server 2022 | Target system |
| Nmap | Network scanning and verification |
| tcpdump | Packet capture and traffic analysis |

## Detection Results

A custom Suricata rule using signature ID `1000003` successfully detected TCP SYN packets from Kali Linux (`192.168.195.130`) to Windows Server 2022 (`192.168.195.134`).

The corresponding events were recorded in EVE JSON, confirming that the configured detection rule matched the observed traffic.

## Key Learning Outcomes

- Understanding network-based intrusion detection.
- Writing and validating custom Suricata rules.
- Investigating TCP SYN traffic and reconnaissance activity.
- Analyzing security alerts and packet captures.
- Distinguishing detection from traffic prevention.
