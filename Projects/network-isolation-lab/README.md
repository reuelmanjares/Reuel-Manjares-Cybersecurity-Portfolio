### 🌐 Network Isolation & OPSEC Lab (Whonix + Kali Linux)

Configured an isolated and anonymized virtual environment designed for secure penetration testing and safe malware analysis.

* **Network Segmentation & Routing:** Successfully routed both Kali Linux and Whonix Workstation traffic exclusively through a Whonix Gateway (Tor network) to ensure strict traffic isolation and prevent IP leaks.
* **System Hardening:** Implemented strict firewall rules using UFW (Uncomplicated Firewall) to control inbound and outbound traffic.
* **Privacy Configuration:** Hardened Firefox browser settings against tracking and de-anonymization by disabling WebRTC, enabling fingerprinting resistance, and enforcing HTTPS-only mode.

**Tools:** VirtualBox, Whonix (Gateway & Workstation), Kali Linux, UFW, Tor.
