
### 🔍 Wazuh SIEM Deployment & Threat Investigation
I deployed an open-source SIEM (Wazuh) in a home lab
environment and performed alert triage on an
authentication failure event tagged under MITRE
ATT&CK T1110 (Password Guessing). Investigated using
volume, severity level, agent source, and timing
pattern to correctly identify it as a false positive
rather than a real brute-force attempt. I utilized 
Kali Linux to perform network scanning, vulnerability identification, 
and simulated brute-force attacks against Wazuh agents 
configured on a Windows Server to validate SIEM detection rules.
**Tools:** Wazuh-server Virtual Appliance, Kali linux, VMware
